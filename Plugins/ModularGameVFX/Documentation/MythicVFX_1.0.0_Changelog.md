# Mythic VFX 1.0.0

发布日期：2026-09-08

- 将冰霜、火焰、奥术、花瓣的法术资产从 /Game 迁到 /MythicVFX/Effects。
- 将角色、动画、环境和演示玩法移到可选 MythicVFXDemo 插件，宿主模块只保留入口。
- 主地图更名为“演示关卡”。
- 以实际用途命名弹体、蓄力、命中、预警、序列帧纹理、材质与网格。
- 发布 8 个法术 ID、13 个 Niagara 组件 ID 和 23 个既有库系统 ID。
- 原通用库保留路径兼容。本轮新法术和既有库的验证范围分别记录。
- 补齐源文件、安装升级工具、文件校验清单、旧路径对照和自动验证脚本。
- 修复通用碎片网格的文件名与对象名不一致，以及一个通用精灵材质的纹理采样类型。
- 移除模板动画失效的编辑预览链接，将所需预览引用指向插件内角色资源。

版本规则：修复且不破坏已发布 ID/参数时升级修订号；新增兼容效果或参数时升级次版本；不兼容路径或接口变更升级主版本，并提供明确迁移记录。宿主定制资产应存放于宿主目录。
