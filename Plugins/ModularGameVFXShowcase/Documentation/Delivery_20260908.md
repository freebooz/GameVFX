## 测试地图和使用入口

按后续明确要求，主入口使用原有怪物地图 `/ModularGameVFXDemo/Maps/演示关卡`。默认保留原生角色、怪物、战斗相机和技能栏；按 F1 打开中文透明特效调试 HUD，再按 F1 返回战斗。宿主模块在该地图开始运行时创建战斗模式的调试控制器，未改写地图原有 GameMode，也不往地图放入独立测试环境。调试模式暂停玩家输入，怪物仍继续运行；关闭调试后恢复原键鼠控制。

独立地图 `/ModularGameVFXShowcase/Maps/L_VFX_Showcase` 仍保留，使用引擎 GameModeBase；Environment 在该地图建立测试起点、目标、角色代理、地面网格、表面墙、环境区和压力测试区。原怪物地图的调试面板隐藏场景改造、测试相机、全局慢放和程序化角色动作控件。

主界面左侧为 Catalog 浏览器，中间为实际 3D 场景和实时计数，右侧为 Inspector、参数、环境与评审控制。右侧可滚动到完整 Review 面板；底部为播放、比较和压力测试操作。

根据后续界面要求，展示界面改为中文透明 HUD，所有控件与运行时场景标签共用 12 点字号。标题通过颜色区分层级，界面采用轻透明底板、暗色透明按钮和文字阴影。分类、元素、状态、质量、参数、评审、运行提示和场景标识使用中文；实际资源路径、GameplayTag、版本与用户输入的证据原文保留。下拉框仅翻译显示，英文枚举与操作键保持稳定；中文元素与形态名称也可用于搜索。

分类使用 Controller 从枚举与 Catalog 生成的进度数据，显示唯一 All 加 15 个功能分类。搜索组合匹配名称、GameplayTag、Element 和 Form。Element、评审状态、收藏、最近使用与排序由同一过滤器处理。注册新 Catalog 条目后刷新即可自动发现，无需增加特效专用按钮。

## Preview 与蓝图调用

```text
WBP 条目的 GameplayTag
→ BP_VFX_ShowcaseController / ExecuteAction
→ ModularGameVFXBlueprintLibrary::PlayVFX
→ 既有 Catalog 和 VFX Manager
→ Niagara
```

Widget 不持有具体 Niagara System 引用，不直接调用 SpawnSystemAtLocation。Profile 按 Tag 保存 AtLocation、Attached、Projectile、Beam、Area、Screen、Environment 等预览模式，以及时长、距离、目标、相机和循环许可。

Cast/Status 使用命名附着点；Projectile 保存每实例三维端点并移动；Beam 传入 Source/Target；Area/Indicator 位于地面；Surface 使用实际测试表面的面位置与法线；World 使用环境区；Screen 使用相机附着层。

Play、Replay、Stop、立即停止、Loop、Auto Preview、Previous/Next、Compare、Combat Simulation、1/5/10/20/50/100 压力测试均通过 Manager 处理。Reset 恢复 Catalog 默认参数，只显示资源实际支持的参数。显式或 Catalog 中的 User.Length 不被自动距离覆盖。

五个质量索引为 VRMobile=0、Low=1、Medium=2、High=3、Cinematic=4，对应真实 Niagara CVar 和 Effect Type 质量设置。离开测试场景时撤销本 Controller 的临时质量覆盖，恢复原值及原设置优先级。
